The 'Critical' cyber model and the AI-improving-AI number

#1 · Cybersecurity · OpenAINov 5“Critical” is OpenAI's own rating

OpenAI launches GPT-6 Cyber, its first 'Critical'-rated cybersecurity model

OpenAI released GPT-6 Cyber, a specialized variant of GPT-6 Astra built for authorized vulnerability discovery, exploit development, and web penetration testing. It scores 48.5% on ExploitGym (vs 32.1% for GPT-5.6 Cyber) and 40.3% vulnerability recall in web-pentesting (vs 32.0% for GPT-6 Astra). OpenAI rates it “Critical” for cybersecurity and “High” for biological and chemical capabilities. Access is initially limited to approved Daybreak Red customers via the API and Codex — a deliberate restriction given the dual-use stakes.

Key players: OpenAI.

#2 · Research · METR / AnthropicNov 5Key evidence redacted

METR finds AI R&D is accelerating inside Anthropic

Independent evaluator METR published a high-access assessment of AI R&D acceleration at Anthropic (Aug 12–Oct 29, 2026), estimating benchmark capability progress has run about 1.9× faster since October 2025 (95% CI 1.5–2.8×). It’s the first hard number on the “AI improving AI” loop from inside a frontier lab. METR itself warns that crucial evidence was redacted, so treat the estimate as directional, not precise.

Key players: METR, Anthropic.

#3 · Security · Anthropic / Xen ProjectDisclosed Nov 3 · Covered Nov 4–5

Claude gets formal credit for finding two critical Xen hypervisor flaws

The Xen Project patched two grant-copy vulnerabilities (CVE-2026-102703, CVE-2026-102704, advisory XSA-523) that let a malicious guest VM read and write the memory of other VMs, including the privileged dom0. Every Xen release from 4.6 onward is affected; patches are out and there is no known mitigation. The advisory credits Anthropic, using Claude, with the discovery — validated by Stephan Lipp of Ada Logics, with CodeAnt’s team independently reporting the same flaws. No known exploitation in the wild.

Key players: Anthropic, Xen Project, Ada Logics, CodeAnt.

Moonshot ships Kimi K3.1 Pro open weights

Moonshot published weights for Kimi K3.1 Pro on Hugging Face: a natively multimodal 2.8T-parameter MoE (104B active, 896 experts) with ~1M context, hybrid attention, and MXFP4 quantization. It’s now the largest publicly downloadable open-weight model, rivaling top proprietary US models — and it launched alongside Kimi Hosted Agents, a managed agent-harness cloud service.
